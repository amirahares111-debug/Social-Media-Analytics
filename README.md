# Social-Media-Analytics
Social Media Analytics Platform

Project Overview

This project focuses on analyzing social media data collected from multiple platforms, including Facebook, Instagram, and YouTube. The goal is to process and analyze large-scale engagement data to identify content performance, audience interaction, and platform trends.

Project Objectives

- Collect and store large social media datasets.
- Analyze user engagement across different platforms.
- Compare content performance between Facebook, Instagram, and YouTube.
- Generate insights to support content creators and marketing decisions.
- Visualize the results using interactive dashboards.

Technologies Used

- Apache Hadoop (HDFS)
- Apache Hive
- HiveQL
- Apache Flume
- Power BI
- GitHub

Dataset

The project analyzes data collected from different social media platforms, including:

- YouTube videos
- Facebook posts
- Instagram posts

The dataset contains information such as:

- Views
- Likes
- Comments
- Shares
- Saves
- Watch Time
- Engagement Rate
- Platform
- Content Type
- Publishing Date

Project Workflow

1. Data Collection using Apache Flume.
2. Store raw data in Hadoop HDFS.
3. Build Hive tables and Data Warehouse.
4. Process and analyze data using HiveQL.
5. Generate business insights.
6. Create Power BI dashboards.
7. Upload the project to GitHub.

Analysis Performed

The project includes analytical queries such as:

- Top viewed content.
- Most liked posts.
- Most commented content.
- Most shared posts.
- Engagement comparison between platforms.
- Best-performing content type.
- Content performance over time.
- Platform performance comparison.
- Audience engagement analysis.
- Trending content analysis.

Dashboard

The Power BI dashboard provides visualizations for:

- Total Views
- Total Likes
- Total Comments
- Total Shares
- Engagement Rate
- Platform Comparison
- Top Performing Content
- Monthly Performance Trends
